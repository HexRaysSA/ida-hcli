2. Key Technical Concepts:
   - `IDAPYTHON_VENV_EXECUTABLE` - IDA-recognized env var pointing to the venv's Python interpreter
   - Windows: PowerShell `[Environment]::SetEnvironmentVariable("name", "value", "User")` replaces `setx` (no 1024-char truncation, broadcasts WM_SETTINGCHANGE)
   - macOS: LaunchAgent plist (`~/Library/LaunchAgents/com.hex-rays.idapython-venv.plist`) + `launchctl setenv` for immediate effect + shell login profile (`~/.zprofile` for zsh)
   - Linux: `~/.config/environment.d/50-hexrays-idapython-venv-executable.conf` for systemd graphical sessions + shell login profile for terminal/SSH
   - Shell login profiles (`.zprofile`, `.bash_profile`) vs interactive profiles (`.zshrc`, `.bashrc`) — env vars belong in login profiles
   - `has_systemd_user()` checks `/run/systemd/system` exists — used to determine if `environment.d` will be read
   - Three-layer architecture: detection predicates → plan builder (pure) → executor (I/O)
   - `ConfigurationPlan` with `ConfigurationStep` dataclasses for the plan/execute pattern
