### 4. `extract_zip_subdirectory_to()` (`install.py:681`)

Extracts a specific subdirectory from a zip archive to a destination path:
1. Stages in trash directory (same filesystem for atomic rename)
2. Validation pass: rejects symlinks, absolute paths, `..` traversals
3. Extraction pass: extracts all files under the specified subdirectory prefix (skips `.git/`)
4. Atomic rename from staging to destination
5. Cleanup on failure

This function already extracts a full subtree including nested subdirectories — a suite archive with components nested inside would be extracted correctly by this function without modification.
