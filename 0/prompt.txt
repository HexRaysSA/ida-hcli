2. Key Technical Concepts:
   - `BasePluginRepo` abstract class with implementations: `JSONFilePluginRepo`, `PluginBundleRepo`, `FileSystemPluginRepo`, `GithubPluginRepo`, `AggregatePluginRepo`
   - `AggregatePluginRepo` wraps multiple named repos, loads lazily, tracks which repo served which plugin via `_owner` dict
   - `PluginBundleRepo` opens a zip containing `plugin-bundle.json` manifest with platform-specific wheelhouses for offline dependency installation
   - Named repos stored in `ida-config.json` under `.Settings.plugin-repositories` as `dict[str, PluginRepositoryConfig]` where `PluginRepositoryConfig` has a `url: str` field
   - Reserved repos (`hexrays`, `community`) have fixed canonical URLs for security (prevent credential harvesting)
   - `repo_for_reference()` resolves a plugin reference to a specific repo (by prefix or default)
   - Install/upgrade commands check `isinstance(repo, PluginBundleRepo)` to use the bundle's wheelhouse for offline pip dependencies
   - `repo_from_url()` factory function infers repo type from URL: `file://` directories → `FileSystemPluginRepo`, `file://` zips with `plugin-bundle.json` → `PluginBundleRepo`, everything else → `JSONFilePluginRepo`

         from hcli.lib.ida.plugin.repo.bundle import PluginBundleRepo, is_plugin_bundle_zip
         from hcli.lib.ida.plugin.repo.file import JSONFilePluginRepo
         from hcli.lib.ida.plugin.repo.fs import FileSystemPluginRepo
         parsed = urlparse(url)
         if parsed.scheme == "file":
             local_path = Path(urllib.request.url2pathname(parsed.path))
             if local_path.is_dir():
                 return FileSystemPluginRepo(local_path)
             if local_path.is_file() and is_plugin_bundle_zip(local_path):
                 return PluginBundleRepo(local_path)
             return JSONFilePluginRepo.from_url(url, repo_name=repo_name)
         return JSONFilePluginRepo.from_url(url, repo_name=repo_name)

         from hcli.lib.ida.plugin.repo.aggregate import AggregatePluginRepo
         if not isinstance(plugin_repo, AggregatePluginRepo):
             return plugin_repo
         plugin = plugin_repo.get_plugin_by_name(plugin_name, host=host)
         owner_name = plugin_repo.repo_of(plugin)
         if owner_name is not None:
             return plugin_repo.get_child_repo(owner_name)
         return plugin_repo
